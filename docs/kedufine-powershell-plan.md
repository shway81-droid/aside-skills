# K-에듀파인 아카이빙 — PowerShell 단독 프로그램 계획

`kedufine-document-archive` 스킬(Aside용)을 **AI 없이 혼자 돌아가는 PowerShell 프로그램**으로
다시 만들기 위한 작업 지시서입니다. 2026-11-21 대화에서 정했고, 아직 만들지 않았습니다.

> **Windows PC에서 시작하는 법:** 저장소를 받은 폴더에서 Claude Code를 열고
> 맨 아래 「첫 세션에 붙여 넣을 요청」을 그대로 붙여 넣으십시오.

---

## 1. 목표

| | 내용 |
|---|---|
| 만드는 것 | 더블클릭으로 실행하는 PowerShell 프로그램 |
| 쓰는 사람 | **AI 없이** 실행합니다. Aside·Claude·Python 모두 필요 없습니다 |
| 만드는 사람 | Claude Code와 함께 만들고 고칩니다 |
| 결과 | `업무파악 > [업무부서명] > [월별 폴더]`에 생산문서 PDF + 건수 보고서 |
| 기존 Aside 스킬 | 그대로 둡니다 |

### 왜 이 방식인가

- 이 작업은 "담당자 × 12개월"을 같은 순서로 반복하는 일이라 판단할 것이 거의 없습니다.
  AI가 매번 화면을 보는 것보다 정해진 순서를 실행하는 프로그램이 빠르고 정확합니다.
- AI가 실행하는 방식(Aside·Claude 스킬)은 **받는 사람도 그 AI가 있어야** 합니다.
  PowerShell은 Windows에 기본으로 들어 있어 동료에게 그대로 나눠 줄 수 있습니다.
- Claude in Chrome 버전을 따로 만들지 않습니다. 실제 화면 확인은 프로그램을 만드는 과정에서
  Claude Code가 브라우저에 직접 연결해 하면 됩니다. Claude in Chrome은 필요할 때 쓰는 보조 도구입니다.

## 2. 구조

```
사용자: 브라우저로 에듀파인 인증서 로그인 → 문서등록대장 화면 열어 둠
          ↓
실행.bat (더블클릭)
  └─ Start-Archive.ps1
       ├─ 담당자.csv 읽기 (담당자, 폴더명)
       ├─ [브라우저] CDP로 이미 열린 브라우저에 연결
       │     담당자·월마다: 조건 입력 → 조회 → 건수 확인 → 전체선택 → PC저장 클릭
       ├─ [저장 창] WXSClient 파일저장 창 처리 (UI Automation)
       ├─ [파일] 새로 생긴 파일을 월별 폴더로, 건수 집계
       └─ 끝나면 폴더 이름을 업무부서명으로 바꾸고 보고서 출력
```

### 예정 파일 구성 (새 폴더 `kedufine-archive-ps/`)

```
kedufine-archive-ps/
  실행.bat              ← 더블클릭용. 브라우저 실행 안내 + Start-Archive.ps1 호출
  Start-Archive.ps1     ← 전체 흐름
  lib/Cdp.ps1           ← 브라우저 연결(WebSocket), 페이지·iframe 안에서 JS 실행
  lib/Edufine.ps1       ← 문서등록대장 조작(조건 입력·조회·건수·전체선택·PC저장)
  lib/SaveDialog.ps1    ← WXSClient 파일저장 창 처리
  lib/Files.ps1         ← 폴더 생성·파일 이동·건수 집계·이름 변경
  담당자.예시.csv        ← ○○ 표기 예시만
  README.md             ← 처음 쓰는 선생님용 안내
```

## 3. 기술 설계 메모

### 3-1. 브라우저 연결 (CDP)

- 브라우저를 원격 디버깅 포트를 켠 상태로 엽니다.
  ```
  msedge.exe --remote-debugging-port=9222 --user-data-dir="%LOCALAPPDATA%\kedufine-archive\profile"
  ```
  최근 Chrome·Edge는 **기본 프로필에서는 디버깅 포트를 무시**하므로 별도 `--user-data-dir`가 필요합니다.
  인증서는 디스크(NPKI 폴더)에 있어서 별도 프로필에서도 로그인할 수 있을 것으로 봅니다(**확인 필요**).
- `http://127.0.0.1:9222/json`에서 문서등록대장 탭의 `webSocketDebuggerUrl`을 찾습니다.
- Windows PowerShell 5.1에 들어 있는 `System.Net.WebSockets.ClientWebSocket`으로 연결합니다.
  외부 모듈은 쓰지 않습니다.
- 화면이 iframe 안에 있습니다. `retrieveDocRegistRegstrList`가 있는 frame을 찾아 그 안에서 JS를 실행합니다.
  - 같은 출처 iframe: `Page.getFrameTree` → `Page.createIsolatedWorld(frameId)` → `Runtime.evaluate(contextId)`
  - 다른 출처 iframe이면 `/json`에 별도 대상으로 나타납니다. 그때는 그 대상에 연결합니다.

### 3-2. 문서등록대장 조작 (기존 SKILL.md 그대로)

| 항목 | 값 / 요소 |
|---|---|
| 경로 | 문서관리 > 문서함 > 문서등록대장 |
| 기안(접수)자 | `#reportr` (패널이 접혀도 값 유지) |
| 결재유형 | 생산 |
| 등록일자 | 월 단위. 패널 접힘 `#basicReportDe`/`#basicReportDe3`, 펼침 `#reportDe`/`#reportDe3` — **보이는 쪽에 입력** |
| 페이지당 | **100건** (30건이면 누락) |
| 건수 확인 | `총 N건 / 조회 M건`에서 N = M |
| 전체선택 | `#chkAll` |
| 비전자문서 | `img[alt^="비전자문서"]` 개수 (부분 일치) |
| 예상 건수 | 전체선택 후 실제 체크된 수 − 비전자문서 수 |
| PC저장 | `a[onclick*="doCallFileManagerExtra"]` |

에듀파인이 업데이트되면 요소 ID가 바뀔 수 있습니다. **요소 ID는 `lib/Edufine.ps1` 맨 위 한곳에 모아**
바뀌었을 때 한 줄만 고치면 되게 합니다.

### 3-3. 저장 창 (WXSClient) — 기존 방식에서 바꿀 점

기존 `save_month.ps1`은 그대로 쓰지 않고 아래 두 가지를 바꿉니다.

1. **다른 프로그램 메모리에 쓰는 방식 제거.** 지금은 폴더 경로를 넣으려고
   `VirtualAllocEx`/`WriteProcessMemory`를 씁니다. 악성코드도 쓰는 기법이라 다른 학교 PC 백신(V3 등)이
   차단할 수 있습니다. 대안(시험해서 고릅니다):
   - **A. 고정 임시 폴더:** 저장 위치를 `업무파악` 안의 `_받는중` 폴더 하나로 고정하고, 저장이 끝나면 PowerShell이
     새 파일을 해당 월 폴더로 옮깁니다. WXSClient가 마지막 저장 위치를 기억한다면 경로 입력 자체가 필요 없습니다.
   - **B. UI Automation:** 폴더 찾아보기 창에 경로 입력칸이 있으면 그 칸에 값을 넣습니다.
2. **좌표 클릭 제거.** 지금은 창 위치 + 고정 좌표(+268, +154 등)로 클릭합니다. 화면 배율(125%, 150%)이
   다른 PC에서 엉뚱한 곳을 누릅니다. UI Automation으로 라디오버튼·버튼 요소를 찾아 누릅니다.

설정값(기존과 같음): 파일구분 = 본문 + 첨부파일, 문서형식 = **배포(PDF 형식)**,
저장형식 = (문서번호 (본문)) 문서의제목.
완료 판단: 새 파일 수가 일정 시간 변하지 않으면 끝난 것으로 봅니다(기존 로직 재사용).

### 3-4. 입력 — 담당자.csv

```csv
담당자,폴더명
최○○,교무기획부
김○○,늘봄학교-돌봄
이○○,늘봄학교-방과후
```

- 엑셀에서 열고 저장할 수 있게 **UTF-8(BOM 포함)**으로 읽고 씁니다.
- 업무분장표에서 이 표를 만드는 일은 1년에 한 번입니다. 사람이 쓰거나 Claude에게 분장표를 주고
  CSV만 뽑아 달라고 하면 됩니다(프로그램 범위 밖).
- 실제 값이 든 `담당자.csv`는 저장소에 올리지 않습니다(`.gitignore`에 추가). 예시는 `담당자.예시.csv`만 둡니다.

### 3-5. 출력 — 보고서

담당자·월별로 `예상 / 저장된 본문 수 / 전체 파일 수 / 차이`를 표로 출력하고 CSV로도 저장합니다.
차이가 나도 오류로 멈추지 않습니다(비전자문서·열람 권한 없는 문서는 시스템이 원래 건너뜀).

### 3-6. 반드시 지킬 것

- **`.ps1` 파일은 UTF-8 BOM으로 저장합니다.** Windows PowerShell 5.1은 BOM 없는 파일을 ANSI(CP949)로 읽어
  `'파일저장'`, `'폴더 찾아보기'` 같은 한글 문자열 비교가 깨집니다. 지금 `save_month.ps1`은 BOM이 없으므로
  재사용할 때 주의합니다.
- 로그인은 자동화하지 않습니다.
- 실행 중 저장 창이 맨 앞으로 튀어나오므로, 시작할 때 "PC를 쓰지 마십시오" 안내를 띄웁니다.
- 한 번에 한 담당자씩도 돌릴 수 있게 합니다(중간에 멈춰도 이어서 실행).

## 4. 시작 전에 Windows PC에서 확인할 것

1. `--remote-debugging-port`와 별도 프로필로 연 Edge(또는 Chrome)에서
   **에듀파인 로그인과 PC저장(WXSClient)이 정상 작동하는지** — 가장 중요합니다
2. PowerShell 스크립트 실행이 허용되는지
   ```
   Get-ExecutionPolicy -List
   ```
   `실행.bat`은 `powershell -ExecutionPolicy Bypass -File ...`로 실행하지만,
   학교 그룹 정책이 막아 두었으면 통하지 않습니다
3. WXSClient가 **마지막 저장 위치를 기억하는지** (3-3의 A안 가능 여부)
4. Claude Code를 설치할 수 있는지 (만드는 사람만 필요)

## 5. 진행 순서

1. 4번 확인 사항 점검
2. `lib/Cdp.ps1` — 브라우저 연결, 문서등록대장 iframe 안에서 `#reportr` 값 읽기까지
3. `lib/Edufine.ps1` — **담당자 한 명·한 달** 조회 → 건수 확인 → 전체선택
4. `lib/SaveDialog.ps1` — PC저장 → 저장 창 처리 → 파일 확인
5. `Start-Archive.ps1` — 한 명 12개월 → 전체 담당자 → 폴더 이름 변경 → 보고서
6. `실행.bat`, `README.md`(처음 쓰는 선생님 기준)
7. 선생님 학교에서 전체 실행 → 결과를 기존 Aside 결과와 비교

## 6. 공유 (완성 후)

- 배포는 이 저장소 링크 하나로 합니다(항상 최신 버전).
- 동료 한두 분께 먼저 시험 배포하고, 막힌 부분을 README에 반영한 뒤 넓게 공유합니다.
- 다른 학교에 자동화 도구를 나눠 주는 것이 **교육청 정보보안 지침**에 걸리지 않는지 확인합니다.
- 에듀파인이 업데이트되면 모든 사용자의 프로그램이 함께 멈춥니다. 고치는 일은 만든 사람 몫이므로,
  요소 ID를 한곳에 모아 둔 구조(3-2)를 지킵니다.

## 7. 저장소 규칙 (CLAUDE.md 요약)

- 작업 시작 전 `git pull`
- 예시에는 실제 학교명·담당자 이름을 쓰지 않습니다(`○○` 표기)
- 커밋 전 `python scripts/check_anonymized.py` (Windows PC에 Python이 없으면 push 후 GitHub 자동 검사로 확인)
- `scripts/check_anonymized.py`는 지금 `.csv`를 검사하지 않습니다. `담당자.예시.csv`를 만들 때
  `.csv`를 검사 대상에 넣고, CSV 첫 칸 이름에 ○가 없으면 잡는 규칙을 추가합니다
